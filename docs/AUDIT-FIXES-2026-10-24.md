## Проверка

- Полный `npm run build`: все проверки интерфейса, сохранения, повторных загрузок, миграций и RLS в изолированной базе, сборка и bundle-тест прошли.
- В Chrome проверен опубликованный проект через локальную производственную сборку. При viewport 760×420 окно фотографии имеет client/scroll size 728×388; при 390×600 — 366×576: внутреннего переполнения нет. Мобильное описание разделено на страницы. Разделителя просмотра нет.
- Обработчик share прочитал реальные опубликованные «Операторский кран для киносъёмки» и «Автоматическая теплица» без записи в базу. Для теплицы также проверено получение WebP-обложки (HTTP 200).
- Изменения схемы рабочей базы и ослабление прав доступа не требуются.

## Границы проверки

Облачные записи и удаления проверены через изолированную базу и подменённую HTTP-границу. Реальные пользовательские данные не использовались для разрушающих сценариев. Предпросмотр в мессенджере может сохранять ранее закешированную карточку до обновления кеша самого сервиса. Новые регрессионные тесты включены в обязательную сборку; они обнаруживают повторение проверенных ошибок, но не гарантируют отсутствие любых будущих дефектов.
