# Добавление внутри разделов

На главной кнопка «Добавить» сохраняет прежнее окно создания главного раздела.
В корневом разделе («Фотография», «Видео» и т. д.) эта же кнопка открывает окно нового подраздела.
Внутри подраздела она открывает окно нового проекта. Во всех случаях используются название,
описание и дроп-зона обложки; родительский раздел фиксируется при открытии окна.

Подразделы и проекты из внутренних страниц сохраняются в Supabase с правами администратора.
Миграцию `007_create_categories.sql` нужно применить после существующих миграций через SQL Editor.
Она добавляет только две защищённые функции; прямой INSERT в таблицу категорий остаётся закрытым.
Подраздел сначала создаётся скрытым, затем загружается обложка и подтверждается публикация.
Новые серверные категории загружаются при старте и восстанавливают вложенность после перезагрузки.

Новый проект сохраняется с обложкой и пустой вкладкой «Обзор», после чего открывается обычная
страница проекта. Кнопка «Редактировать» ведёт в существующий редактор. Ошибка сохранения
оставляет модальное окно и введённые данные открытыми для повтора.

Проверки: `tests/card-creation-ui.mjs`, `tests/card-creation-service.mjs`,
`tests/category-creation-db.mjs` и общая команда `npm run build`.
