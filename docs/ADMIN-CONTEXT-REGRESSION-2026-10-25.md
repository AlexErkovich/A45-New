# A45-New — регрессия административного контекста

## Подтверждённая причина

В существующей локальной вкладке с настоящей сессией Supabase воспроизведено: `/admin` → плитка «Техническое творчество» → `/admin#/category/technical`, затем кнопка «Фотография» в левом дереве → `/#/category/photography`. Кнопки управления и служебный footer исчезали одновременно с уходом на публичный маршрут.

Причина в `app.js`: обработчик корневого блока передавал `#/category/<id>` в `history.pushState()`. Браузер разрешает относительный адрес History API относительно document base URL. При `<base href="/">` это публичный `/`, а не текущий `/admin`. Публичный render правильно очищал административные инструменты и editing-state; сама сессия Supabase не терялась.

Эта строка присутствует и в сохранённой версии до последней корректировки анимаций (`/tmp/a45-motion-before/app.js`). Следовательно, анимации не являются первопричиной ухода на публичный маршрут. Откатывать их, footer или прокрутку не требуется.

Исправление: обработчик передаёт явный `location.pathname + location.search + '#/category/<id>'`; сравнивается полный текущий адрес. Административный путь сохраняется, публичный путь остаётся публичным. Ссылки вкладок, карточек и возврата проверены отдельно: в admin они имеют `/admin#/...`.

Дополнительно подтверждено, что флаг выбора карточек существовал только в памяти JS и терялся при полной перезагрузке. Теперь его значение сохраняется в `sessionStorage` текущей вкладки под `a45-admin-listing-edit` и восстанавливается только после успешной проверки административного допуска. «Готово» и публичный/login render очищают значение; оно не предоставляет прав и не подменяет Supabase Auth/RLS. Canvas по собственному административному URL по-прежнему восстанавливается существующим редактором.

При включённом выборе карточек обычный клик открывает существующий модальный редактор метаданных — это предусмотренное поведение, оно не менялось. Для перехода к полному просмотру проекта в этой проверке использовался его уже сформированный административный URL. Публичный Share остаётся публичным.

## Постоянные регрессии и безопасность

`tests/system-navigation.mjs` и `tests/built-admin.mjs` теперь разрешают URL History API относительно `document.baseURI`, воспроизводя поведение браузера, которого не хватало Happy DOM. Добавлены реальные обработчики кликов по корневым блокам, проверки pathname, допуска, editing-state, ссылок подразделов, восстановления после reload и очистки по Done/отказу в доступе. Эти тесты уже входят в существующую безопасную сборку; матрица также входит в test/admin-safe/publication-safe.

Отрицательная проверка вне репозитория (`/tmp/a45-admin-negative-regression.mjs`) с сохранённым кодом до исправления ожидаемо падает на `tree click must preserve admin with a document base`. Рабочие файлы при этом не подменялись. Исправленная версия проходит.

В этой работе последовательно прошли system-navigation, access-control, public-admin-pages, session-navigation, editor-save-smoke, card-creation-ui, management-navigation, navigation-motion, card-motion, production build и built-admin. Основная матрица: 119 переходов, 117 свежих DOM-открытий; сверх неё — 12 корневых кликов и проверки восстановления режима. Это моделируемые открытия, не native reload. Реальные переходы и reload дополнительно проверялись в уже открытой локальной вкладке без запуска нового браузера.

Лимиты автоматических процессов: V8 old heap 256 МиБ, RSS группы 512 МиБ, 60 секунд на проверку, 64 КиБ вывода. Максимальный измеренный RSS — **183 МиБ**. Контроллер подтвердил очистку дочерних процессов. Новый Chrome, тяжёлые браузерные/БД-тесты и параллельные наборы не запускались. RSS относится к контролируемым тестовым группам, не ко всему уже открытому браузеру пользователя.

## Изменения и состояние публикации

Изменены только `app.js`, `tests/system-navigation.mjs`, `tests/built-admin.mjs` и этот отчёт. `dist` пересобран. Дизайн, карточки, CSS, навигационная структура, анимации, footer, модальные кнопки и код Supabase Auth/редактора не менялись. Все прежние неопубликованные изменения сохранены. Копии затронутых файлов до работы: `/tmp/a45-admin-regression-before/`.

Не выполнялись commit, push, deployment, SQL, миграции, Auth Admin API, изменения проектов/категорий/фотографий/текстов/RLS/Storage. Выполнялись обычная авторизация по уже сохранённой сессии, чтение разрешённых материалов и предусмотренный выход текущей локальной сессии.

Локальный сервер: **http://127.0.0.1:3002/**; управление: **http://127.0.0.1:3002/admin**. После проверки выхода требуется самостоятельный вход пользователя.

Уход в public и потеря режима после reload исправлены и проверены. **Полную проверку всех критериев завершения не объявляю:** настоящее сохранение production-материалов и последующий серверный readback намеренно не выполнялись. Для независимой проверки записи без риска настоящим данным нужен отдельный тестовый Supabase-проект/изолированное окружение. Готовность к публикации этим отчётом не подтверждается.
