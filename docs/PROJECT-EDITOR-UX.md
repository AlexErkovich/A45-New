# Редактор страницы проекта

Создание и редактирование используют один интерфейс, похожий на просмотр проекта. Новая страница содержит название и пустую вкладку «Идея». Название получает фокус при открытии. Текст и заголовки редактируются на месте; поля растут по содержимому.

У блока при наведении или фокусе появляются плюс и ручка перемещения. Плюс открывает добавление текста, заголовка, фото, карусели, разделителя, видео или документа, а также действия с текущим блоком. Ручка поддерживает перетаскивание и меню перемещения выше/ниже. На сенсорном устройстве элементы доступны постоянно.

Вкладки расположены под названием. При наведении подсвечивается вся полоса вкладок и показывается общая пара кнопок: плюс и ручка для выбранной вкладки. Меню позволяет добавить, переименовать, удалить или переместить вкладку. Создание и редактирование используют один компактный диалог: название и «Сохранить». После создания выбирается новая вкладка, её блоки добавляются на странице. Иконки и повторяемые элементы берутся из общего модуля `src/ui/components.mjs` (Lucide). Выпадающие меню размещаются в пределах экрана и при нехватке места открываются над кнопкой. Последнюю вкладку удалить нельзя. Удаление вкладки с содержимым требует подтверждения.

Вкладка фотографий содержит большую дроп-зону и явную кнопку «Загрузить фотографии». Во вкладке фотографий ровно одна дроп-зона; большие изображения и отдельные зоны галерей в редакторе не выводятся. Под ней — компактные строки файлов: миниатюра, имя, индивидуальный лоадер, затем галочка и кнопка удаления. Ошибка даёт повторную попытку. Файл можно убрать во время обработки; отменённый файл не добавляется после завершения фоновой подготовки. Успешные файлы сохраняются в черновике даже при ошибке соседнего файла. Оригиналы и варианты отправляются в облако при Save, а не при выборе файла.

После успешного Save открывается просмотр самого проекта; при ошибке редактор остаётся открытым. Save сохраняет текущий статус проекта, «Опубликовать» публикует его. Ошибка сохраняет введённый текст и подготовленные файлы в памяти вкладки; уход с несохранёнными изменениями требует выбора сохранить/не сохранять. Для локальных примеров используется хранилище браузера, для облачных материалов — существующие серверные проверки доступа.

Порядок и типы вкладок сохраняются в служебном текстовом блоке, который не показывается читателю. В RPC первая вкладка остаётся `overview` для совместимости с текущей схемой базы. Разделитель сохраняется как текстовый блок с признаком `divider`. Старый боковой интерфейс, библиотека фотографий и формы каждого блока удалены.

## Карточка и содержимое

В списке любого раздела/подраздела «Редактировать» включает выделение карточек. Клик по проекту открывает общее модальное окно названия, обложки и описания. Сохранение оставляет пользователя в списке; табы, блоки, статус и категории проекта сохраняются без изменений. Внутри открытого проекта «Редактировать» ведёт в полный редактор содержимого. Сохранение карточки реализовано отдельно в src/project-card.mjs и использует тот же сервис записи проекта.
