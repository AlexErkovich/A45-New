# Редактор страницы проекта

Создание и редактирование используют один интерфейс, похожий на просмотр проекта. Новая страница содержит название и пустую вкладку «Идея». Название получает фокус при открытии. Текст и заголовки редактируются на месте; поля растут по содержимому.

У блока при наведении или фокусе появляются плюс и ручка перемещения. Плюс открывает добавление текста, заголовка, фото, карусели, разделителя, видео или документа, а также действия с текущим блоком. Ручка поддерживает перетаскивание и меню перемещения выше/ниже. На сенсорном устройстве элементы доступны постоянно.

Вкладки расположены под названием. При наведении подсвечивается вся полоса вкладок и показывается общая пара кнопок: плюс и ручка для выбранной вкладки. Меню позволяет добавить, переименовать, удалить или переместить вкладку. Создание и редактирование используют один компактный диалог: название и «Сохранить». После создания выбирается новая вкладка, её блоки добавляются на странице. Иконки и повторяемые элементы берутся из общего модуля `src/ui/components.mjs` (Lucide). Выпадающие меню размещаются в пределах экрана и при нехватке места открываются над кнопкой. Последнюю вкладку удалить нельзя. Удаление вкладки с содержимым требует подтверждения.

Вкладка фотографий содержит большую дроп-зону и явную кнопку «Загрузить фотографии». Во вкладке фотографий ровно одна дроп-зона; большие изображения и отдельные зоны галерей в редакторе не выводятся. Под ней — компактные строки файлов: миниатюра, имя, индивидуальный лоадер, затем зелёная галочка. Готовая строка открывает общий просмотр фотографий; удаление готового снимка доступно в карусели. Ошибка даёт повторную попытку. Файл можно убрать во время обработки; отменённый файл не добавляется после завершения фоновой подготовки. Успешные файлы сохраняются в черновике даже при ошибке соседнего файла. После выбора файла оригинал и оптимизированные варианты сразу отправляются в Supabase. Галочка означает завершённую серверную загрузку. Изменения текста, вкладок и размещения фотографий в опубликованном проекте вступают в силу только после Save.

После успешного Save открывается просмотр самого проекта; при ошибке редактор остаётся открытым. Save сохраняет текущий статус проекта, «Опубликовать» публикует его. Ошибка сохраняет введённый текст и подготовленные файлы в памяти вкладки; уход с несохранёнными изменениями требует выбора сохранить/не сохранять. Проекты и фотографии сохраняются только на сервере после проверки администратора, в том числе при работе через localhost. Старые локальные данные доступны только для переноса.

Порядок и типы вкладок сохраняются в служебном текстовом блоке, который не показывается читателю. В RPC первая вкладка остаётся `overview` для совместимости с текущей схемой базы. Разделитель сохраняется как текстовый блок с признаком `divider`. Старый боковой интерфейс, библиотека фотографий и формы каждого блока удалены.

## Карточка и содержимое

В списке любого раздела/подраздела «Редактировать» включает выделение карточек. Клик по проекту открывает общее модальное окно названия, обложки и описания. Сохранение оставляет пользователя в списке; табы, блоки, статус и категории проекта сохраняются без изменений. Внутри открытого проекта «Редактировать» ведёт в полный редактор содержимого. Сохранение карточки реализовано отдельно в src/project-card.mjs и использует тот же сервис записи проекта.

Переход из просмотра в редактирование сохраняет текущую страницу до готовности серверных данных, открытую вкладку и прокрутку. Промежуточной страницы «Загрузка редактора» нет. Шапка сайта с логотипом/служебными ссылками и подвал скрыты уже при входе в режим. При ошибке загрузки содержимое проекта остаётся на месте с сообщением внутри страницы.

## Повторное использование фотографий

В меню добавления блока есть действие «Из вкладки „Фотографии“». Оно открывает выбор уже загруженных фотографий проекта. Выбранные снимки вставляются в текущую вкладку без повторной загрузки файлов. Длинные описания в общем просмотрщике разбиваются на страницы; навигация по фотографиям и описанию независима.

Шапка редактора с названием и вкладками оформлена как шапка просмотра проекта. Save и публикация остаются отдельными действиями.

Просмотр фотографии ограничен текущей шириной и высотой окна браузера. На низком окне уменьшаются отступы и размер текста, на узком — фотография и описание располагаются вертикально. Описание делится на страницы с компактной навигацией; при изменении размера сохраняется место чтения. Пустой блок действий и разделительная линия не выводятся в просмотре; элементы редактирования остаются в редакторе. Проверены размеры 1000×600, 760×420 и 390×600 без внутреннего переполнения окна.


## Уточнения аудита 24 октября 2026

Модальные формы используют общую закреплённую шапку с кнопкой закрытия. Ошибки и подтверждения выводятся общим tooltip-компонентом без сдвига формы. Подписанные ссылки медиа обновляются через ограниченный кеш с TTL и восстанавливаются на месте; замена URL не должна перестраивать читаемую страницу. См. [отчёт](AUDIT-FIXES-2026-10-24.md).


## Действия со вкладками

Плюс слева от панели открывает общее меню: «Переместить», «Добавить вкладку», «Редактировать», «Удалить». Перемещение, редактирование и удаление включают взаимоисключающий режим с соответствующей иконкой у каждой вкладки. Действие применяется к выбранной иконке, а не автоматически к активной вкладке. Перемещение поддерживает перетаскивание и меню направлений. Добавление сразу открывает общее окно новой вкладки и завершает режим. Крестик или Escape завершают режим; удаление подтверждается, последняя вкладка защищена. Выбранная вкладка сохраняется при перемещении или удалении соседней.
