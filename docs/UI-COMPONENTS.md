# Общие компоненты A45

Иконки: [Lucide](https://lucide.dev/icons/), бесплатная библиотека с открытой лицензией ISC. Лицензия включена в `assets/licenses/lucide.txt`. Пакет `lucide-react` установлен локально; сборка не загружает иконки с CDN.

`node scripts/generate-icons.mjs` создаёт два представления одного набора: `src/ui/icons.mjs` для модулей и `window.A45Icons` в `icons.js` для обычных страниц. Новые иконки добавляются в список официальных компонентов в этом скрипте. Собственные SVG и Unicode-подмены для новых элементов не используются.

`src/ui/components.mjs` — общий источник повторяемой разметки:

- `icon(name)` — официальная SVG-иконка.
- `iconButton({name,label,attributes,className})` — кнопка с доступным названием, одинаковым размером и ховером.
- `editorTools(scope,id)` — действия и рабочая ручка перетаскивания блока/вкладки.
- `uploadDropzone(options)` — единая дроп-зона для обложек, изображений, каруселей и документов; визуальные состояния, превью и кнопка одинаковые во всех местах.
- `photoDropzone(options)` — тот же компонент, настроенный на несколько фотографий.
- `bindDropzones(root)` — общее открытие файлового поля; `setDropzoneState()` — состояния загрузки, ошибки и превью.
- `actionItem(...)` — строка меню с иконкой.
- `categoryPicker()` / `bindCategoryPicker()` — общий выбор раздела и подраздела из текущего каталога.
- `openPhotoCarousel()` / `openPhotoDialog()` — единый просмотр и редактирование фотографий; реализация в `src/ui/photo-carousel.mjs`, импорт через `components.mjs`.

`src/auth-form.mjs` — единый экран входа для `/login` и совместимого `/admin`. Компактная двухколоночная композиция с оригинальным логотипом A45 и полями высотой 40 px; на узком экране — одна колонка. Проверки настоящих прав администратора отделены от оформления.

Для обычных страниц эти функции доступны как `window.A45UI`. Базовые размеры, цвета, расстояния и состояния задаются в `ui.css`, настройки редактора — в `admin.css`. Компоненты нужно переиспользовать, а изменения общего поведения вносить в исходный компонент.

Все загрузки на главной, в формах разделов/подразделов/проектов, inline-блоках редактора и совместимой админке используют эту разметку. В styles.css и admin.css нет отдельных стилей дроп-зон. Лимиты и разрешённые типы файлов задаются параметрами и соответствуют фактическим проверкам конкретного сценария.

`src/ui/page-drop.mjs` обеспечивает общую подсветку всего экрана при перетаскивании файлов и приём файла из любой точки страницы. Открытый диалог имеет приоритет, прямое попадание в дроп-зону выбирает её. Тексты и внутреннее перемещение блоков не активируют загрузку. Отпускание файла, Escape, уход курсора и смена страницы убирают подсветку.

`uploadFileList()` показывает состояние каждой фотографии: очередь, подготовка, ожидание Save, загрузка, серверное сохранение, успех или ошибка. Крутящийся индикатор включается только во время активной операции. Сервис передаёт состояние по `mediaId`, поэтому одинаковые имена файлов не смешивают прогресс. Галочка появляется после успешной серверной загрузки фотографии. Размещение снимков и изменения опубликованной страницы подтверждаются отдельным Save. Статусы редактора с `data-feedback-inline` не превращаются в тултипы.

`openProjectPhotoPicker()` — общий диалог выбора фотографий из вкладки «Фотографии» для повторного размещения в других вкладках без повторной загрузки.


## Уточнения аудита 24 октября 2026

Модальные формы используют общую закреплённую шапку с кнопкой закрытия. Ошибки и подтверждения выводятся общим tooltip-компонентом без сдвига формы. Подписанные ссылки медиа обновляются через ограниченный кеш с TTL и восстанавливаются на месте; замена URL не должна перестраивать читаемую страницу. См. [отчёт](AUDIT-FIXES-2026-10-24.md).


## Документы

Общие компоненты: documentDropzone / uploadFileList в components.mjs, documentGrid / documentRow / fileBadge / fileSize в document-types.mjs и openDocumentDialog в document-dialog.mjs. Иконки типов файлов генерируются из бесплатной Lucide React. PDF-просмотр — отдельный лениво загружаемый модуль pdf-preview.mjs (Mozilla PDF.js, Apache-2.0), без iframe и внешних сервисов.

Карточки документов показывают тип файла без фоновой плашки и оранжевую иконку скачивания с доступной подписью. Название обрезается многоточием; нативный tooltip с полным названием добавляется при наведении или фокусе только при фактическом переполнении текста.


## Единые кнопки действий

Текстовые действия используют actionButton() из buttons.mjs и классы ui-button / ui-button--primary / ui-button--outline. Высота 40 px, радиус 8 px, отступы 10×18 px, шрифт Inter 12/18, один акцент #ed5938. Основные действия залиты; вторичные и удаление — контурные. Удаление подписывается «Удалить» без иконки. Общие стили применены к формам разделов, редактору проектов, свойствам, входу, переносу данных, фильтрам, подтверждениям, дроп-зонам и окнам медиа. Иконки в сетке документов остаются отдельным icon-only компонентом.

В окне документа слева расположено контурное «Удалить», справа — залитое «Скачать». Видимый общий заголовок «Документация» убран; доступное название диалога сохранено.

Сетка документов разделяется одной линией #eee толщиной 1 px между визуальными рядами. На разных ширинах линия охватывает три, две или одну колонку; после последнего ряда не рисуется. В редакторе применяется тот же document-grid.


## Единое окно файлов

openMediaDialog() в media-dialog.mjs — единственный компонент просмотра и редактирования фотографий, PDF, текста и прочих файлов. openPhotoCarousel(), openPhotoDialog() и openDocumentDialog() теперь только адаптируют данные к нему; отдельных окон у них нет.

Общие элементы: размеры и адаптивная раскладка, заголовок «Название файла», метаданные, постраничное описание, миниатюры или типы файлов в одной ленте, стрелки и клавиатура, кнопки «Удалить» / «Скачать», подтверждение удаления, повтор загрузки и закрытие. Скачивание доступно только документам; у фотографий этой кнопки нет ни в просмотре, ни в редакторе. Управление обложкой доступно только для изображений в редакторе. Различается только рендер содержимого и доступные для формата действия.


## Эталон внешнего вида окна файлов

По скриншоту пользователя восстановлен исходный фото-макет для всех форматов: окно до 1230 px, две колонки 2.05:1 с промежутком до 96 px, предпросмотр 3:2 со скруглением 40 px, стрелки непосредственно по бокам кадра, центрированная лента миниатюр под ним, поля названия и описания справа. Отдельной нижней панели со счётчиком и дополнительной строки метаданных в окне нет. Общее окно использует высоту по содержимому, а не растягивается до максимальной высоты. На мобильной ширине тот же компонент адаптируется в одну колонку. Не заменять этот макет новым при изменении логики документов.
